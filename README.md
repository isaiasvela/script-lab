# Script Lab

A collection of utility scripts for everyday tasks.

## Overview

This repository contains a curated set of scripts designed to automate common tasks. Each script lives in its own folder with a dedicated README explaining what it does and how to use it.

## Project Structure

```text
.
├── file-organizer/       # Organizes files by extension
│   ├── file-organizer.sh
│   └── README.md
└── README.md             # This file
```

## Scripts

| Script | Language | Description | Documentation |
| ------ | -------- | ----------- | ------------- |
| file-organizer | Bash | Organizes files into directories named with their extension | [README](file-organizer/README.md) |

## Convention

- Each script lives in its own folder with a `README.md` explaining its purpose, usage, and requirements.
- If a script grows too complex and needs multiple files (libraries, configs, etc.), it will be moved to a separate repository and linked here.
- This repository acts as an index of scripts.

## Requirements

Requirements vary by script. Check the README in each script's folder for details.

## Usage

Each script has its own usage instructions. Navigate to the script's folder and refer to its README.
